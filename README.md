# Session 2 Tasks — C++

C++ solutions for the Session 2 Codeforces assignment.

## Required
- A+B Again?
- Sum
- Short Sort
- Sorting (Bubble Sort, without built-in sorting functions)

## Optional practice
- Plus or Minus
- Stair, Peak, or Neither?
- Count
- Pyramid

Each problem is saved in its own `.cpp` file. Submit each solution separately on Codeforces and verify that it receives an Accepted (AC) verdict before considering the assignment complete.
